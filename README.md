# ⏱️ TimestampLogger

> **Автоматическая фиксация таймкодов при паузе на YouTube и в медиаплеерах Windows.**  
> *Auto-pause timestamp logger for YouTube and Windows desktop media players.*

---

## 🇷🇺 Русская версия (Russian)

Утилита для Windows, которая автоматически отслеживает нажатие паузы при воспроизведении видео или аудио и сохраняет точные таймкоды в структурированные текстовые файлы (`timestamps/`).

Работает в системном трее Windows (фоновый режим), поддерживает белые/черные списки (Whitelist / Blacklist) и имеет удобное графическое окно настроек.

---

### ✨ Возможности
* 🎯 **Автоматический трекинг паузы:** Сохраняет таймкод (`01:23:45`), заголовок трека/видео и автора при каждой паузе.
* 🖥️ **Поддержка YouTube и браузеров:** Chrome, Firefox, Edge, Opera, Яндекс.Браузер (через Windows Media Manager или скрипт Tampermonkey).
* 🎵 **Поддержка десктопных плееров:** Яндекс Музыка, Spotify, VK Музыка, AIMP, MPC-HC, VLC и любые приложения с интеграцией системных медиа-клавиш Windows (SMTC).
* ⚙️ **Фильтрация медиа (GUI):**
  * **Whitelist (Белый список):** Сохранять таймкоды только для указанных видео/треков.
  * **Blacklist (Черный список):** Сохранять таймкоды для всего, кроме указанных исключений.
* 🗔 **Системный трей Windows:** Приложение тихо работает в фоне возле часов. Двойной клик или клик правой кнопкой мыши открывает статус, текущее медиа и списки фильтров.
* 📁 **Аккуратные логи:** Логи складываются в папку `timestamps/` в формате `.txt` с группировкой по дням или названиям видео.

---

### 🚀 Быстрый старт (Без установки Python)

Самый простой способ — использовать готовый собранный `.exe`:

1. Перейдите в раздел **[Releases](https://github.com/lTortugal/TimestampLogger/releases)** справа на странице репозитория.
2. Скачайте файл **`TimestampLogger.exe`**.
3. Запустите файл. Рядом с часами в трее появится иконка программы.
4. При первой паузе видео в этой же папке автоматически создастся папка `timestamps/` с вашими таймкодами.

> ℹ️ *Примечание:* При первом запуске Windows SmartScreen может показать синее предупреждение («Неизвестный издатель»). Нажмите **«Подробнее» (More info) ➔ «Выполнить в любом случае» (Run anyway)**. Это стандартная реакция Windows на любые самостоятельные `.exe`, собранные без платного корпоративного сертификата.
